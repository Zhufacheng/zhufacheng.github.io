# Test

用來驗證 GitHub Pages 的建置與導覽是否正常（新增目錄 → 頁面可連到 → 樣式正確）。後續實際內容會從這裡搬遷到對應主題頁。

## 檢查清單

- [ ] 根目錄 [index](../) 連得進來本頁
- [ ] 本頁可連回 [OpenBMC](../openbmc/) 各主題頁
- [ ] `_config.yml` 的 `title` 正確帶入瀏覽器分頁標題
- [ ] 相對連結（trailing slash 目錄式連結）在 Pages 上解析正常

## 頁面慣例（新增主題頁時沿用）

1. 一個主題一個目錄：`<topic>/index.md`，方便用 `./<topic>/` 這種目錄式連結。
2. 根 `index.md` 只列分区入口，細節留在各主題頁。
3. 主題頁的固定骨幹：一句話定位 → 背景概念 → 怎麼運作（含 ASCII 流程圖）→ 相關專案 / daemon → D-Bus → 新手常問。
